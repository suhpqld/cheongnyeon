# 03 음성과 AI (말하기 버튼, 말 읽기, 주민센터에서 할 말)

> **AI에게:** `docs/00_공통_먼저읽기.md`를 먼저 끝까지 읽는다. AI 호출은 01의 `lib/server/ai.ts`의 `callAI`, 호출 상한은 `useAiCall`, 인증은 `requireApp`을 쓴다. 고치지 않는다.

## 이 기능이 하는 일
1. **말하기 버튼**: 브라우저 음성 인식으로 말을 받아 글로 바꾸고, 크게 "듣고 있어요"를 보여 준다.
2. **말 읽기 AI** (`/api/extract`): 사람이 한 말을 신청서 칸 값(JSON)으로 바꾼다. 대충 말한 금액, 모른다는 말, 여러 칸을 한 번에 말한 것도 알아듣는다.
3. **주민센터에서 할 말 AI** (`/api/card-script`): 창구에서 그대로 읽으면 되는 2~3문장을 쓴다. (04가 부른다)
4. **시연 기기 시험 화면**: 한국어 음성 인식과 읽어 주기가 되는지, 프롬프트가 잘 읽는지 시험한다.

## P0-1. 음성 인식 훅 `lib/client/stt.ts`
```ts
useSpeechRecognition(): {
  supported: boolean;          // SpeechRecognition || webkitSpeechRecognition
  listening: boolean;
  interim: string;             // 말하는 중간 글
  finalText: string;
  error: null | 'denied' | 'no-speech' | 'network' | 'other';
  start(): void;               // 읽어 주기(tts.stopSpeaking) 먼저 멈춤
  stop(): void;
}
```
- `lang = 'ko-KR'`, `interimResults = true`, `continuous = false`, `maxAlternatives = 1`
- 말이 끝나면(onend) 자동으로 멈추고 `finalText` 확정
- HTTPS에서만 마이크가 된다 (localhost와 Vercel 주소는 됨)

### 시스템 프롬프트 `EXTRACT_SYSTEM` (시작점. 이건희가 시험하며 다듬는다)
```
너는 복지 신청서 작성을 돕는 도우미 "복냥이"의 말 읽기 담당이다.
사용자가 쉬운 질문에 말로 대답한 내용에서, 현재 질문(field)의 답을 뽑아 JSON으로만 답한다.
말하는 사람은 신청하는 어르신 본인일 수도 있고, 옆에서 돕는 가족이나 도우미일 수도 있다 (helperMode).
"우리 엄마는 혼자 살아"처럼 가족이 대신 말하면 신청하는 분에 대한 답으로 읽는다.

규칙
1. type별 value 형식
   - yes_no: true 또는 false
   - choice: options의 value 중 하나 (label이 아니라 value)
   - district: 서울 구 이름 전체 ("노원" → "노원구")
   - count: 정수 ("혼자" → 1, "둘이 살아" → 2, "나랑 아들이랑 손주" → 3)
   - money: 원 단위 정수 ("30만 원" → 300000, "이십오만" → 250000, "1억 5천" → 150000000, "없어" → 0)
     보증금과 전세금에서 단위 없이 "오백", "천"이라고 하면 만 원 단위로 본다 ("보증금 오백" → 5000000)
   - text: 짧게 정리한 글 ("상계동이요" → "상계동")
2. "한 30만 원쯤", "대충", "아마", "정도", "한"처럼 어림으로 말하면 value는 그 숫자로 하고 isApproximate를 true로 한다.
3. 모른다고 하면 ("몰라", "기억 안 나", "잘 모르겠어") allowUnknown이 true일 때만 value를 "unknown"으로 한다. 아니면 confidence를 "low"로 한다.
4. 확실하지 않거나 질문과 상관없는 대답이면 confidence를 "low"로 하고,
   clarifyQuestion에 예, 아니오나 짧은 선택으로 답할 수 있는 쉬운 존댓말 질문 한 문장을 쓰고,
   clarifyOptions에 선택지를 준다. 선택지의 value는 그 field의 value 형식을 따른다.
   예: 집 질문에 "빌려서 살아" → clarifyQuestion "다달이 월세를 내세요?" / 선택지 [{"label":"월세를 내요","value":"monthly"},{"label":"전세예요","value":"jeonse"},{"label":"돈 안 내요","value":"free"}]
5. clarify가 주어지면, 그 되묻는 질문에 대한 대답으로 읽는다.
6. heardAs는 사람이 읽기 쉬운 결과다 ("월세예요", "25만 원", "약 30만 원", "1명 (혼자)", "노원구").
7. otherFields의 질문에 대한 답이 말에 분명히 들어 있으면 otherValues에 넣는다. 분명하지 않으면 넣지 않는다.
8. 수급 가능 여부를 판단하거나 말하지 않는다. 이름, 주민등록번호, 계좌번호, 전화번호는 출력하지 않는다.
9. 출력은 아래 JSON 하나뿐이다.
{"value": ..., "confidence": "high"|"low", "isApproximate": true|false, "heardAs": "...", "clarifyQuestion": null|"...", "clarifyOptions": null|[{"label":"...","value":...}], "otherValues": [{"key":"...","value":...,"isApproximate":false}]}
```
- user 메시지: `{ helperMode, field, otherFields, clarify, utterance }` JSON 문자열

## P0-4. 직접 읽기 `lib/parse-korean.ts` (AI 실패 대비, 브라우저와 서버 둘 다)
| 함수 | 예 |
|---|---|
| `parseKoreanMoney(text)` | "30만 원" 300000 / "삼십만 원" 300000 / "이십오만" 250000 / "한 백만 원쯤" 1000000 (+ approximate) / "1억 5천만" 150000000 / "천오백만 원" 15000000 / "없어요" 0 / 그 밖에 null |
| `parseYesNo(text)` | "예, 네, 응, 어, 그래, 맞아, 있어, 있어요" true / "아니, 아뇨, 아니요, 없어, 없어요" false / 그 밖에 null |
| `parseCount(text)` | "혼자" 1, "둘" 2, "셋" 3, "네 명" 4, "3명" 3 / 그 밖에 null |
| `matchDistrict(text)` | 글 안에 구 이름(또는 "구"를 뺀 이름)이 있으면 그 구 / 없으면 null |
| `isUnknownSpeech(text)` | "몰라, 모르겠, 기억 안" 포함이면 true |
| `isApproxSpeech(text)` | "쯤, 정도, 대충, 아마, 한 " 포함이면 true |
| `localExtract(field, text): ExtractResult` | 위 함수로 field type에 맞게. 실패면 value null, confidence low |

## P0-5. 주민센터에서 할 말 API `POST /api/card-script`
1. zod 검사 (`CardScriptRequest`) → `requireApp` → `useAiCall`
2. `callAI({ kind: 'text', system: CARD_SCRIPT_SYSTEM, user: JSON.stringify(요청) })` → `{ script }` zod 검사
3. 실패하면 **틀 문장**으로 대신:
   - 기본: "{제도 이름} 신청하러 왔어요. 같이 사는 사람은 {n}명이에요. {확인 필요가 있으면: 정확히 모르는 것이 있어서 같이 확인해 주세요.}"
   - 추가 서류만: "추가 서류 내러 왔어요. {서류 이름들} 가져왔어요."
4. 응답 `{ script }`

### `CARD_SCRIPT_SYSTEM`
```
너는 복지 신청을 돕는 도우미 "복냥이"다.
신청하는 분이나 대신 간 가족이 주민센터 창구에서 그대로 읽으면 되는 말을 2~3문장으로 쓴다.

규칙
1. 첫 문장은 무엇을 하러 왔는지. 예: "서울형 기초보장제도 신청하러 왔어요." 추가 서류를 내러 왔으면 "추가 서류 내러 왔어요."
2. applicantType이 family면 "어머니 대신 왔어요"처럼 쓰되 관계를 모르면 "가족 대신 왔어요", other면 "신청하시는 분을 도와드리러 왔어요".
3. 둘째 문장은 가구와 집 상황 중 가장 중요한 것 한두 개 (answerLines에서).
4. checkLabels가 있으면 "{칸}은 정확히 몰라서 같이 확인해 주세요."처럼 부탁하는 문장을 넣는다.
5. 쉬운 존댓말, 짧은 문장. 이름, 주민등록번호, 전화번호는 쓰지 않는다.
6. "받을 수 있어요", "대상이에요" 같은 판정 표현을 쓰지 않는다.
7. 출력: {"script": "..."}
```
