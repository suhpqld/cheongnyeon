## 1. PM이 개발과 별개로 할 일

### 1-1. 주민센터 수용 여부 확인 (피드백 기획 1, 발표에 꼭 넣기)
- 오늘은 토요일이라 주민센터는 쉰다. **120 다산콜재단**에 전화해서 묻는다.
- 물어볼 말:
  1. "복지 신청할 때 사회보장급여 신청서를 집에서 미리 출력해서 채워 가도 접수가 되나요?"
  2. "안 된다면, 창구에서 신청서를 쓸 때 정리해 온 메모를 보면서 옮겨 써도 되나요? 직원분께 보여 드려도 되나요?"
  3. "주민센터에서 보완 서류를 다시 달라고 하는 경우가 많은 서류가 있나요?"
- 답을 그대로 적어 둔다 (날짜, 시간, 상담 내용). 발표 슬라이드 한 장: "확인 결과: ...  그래서 복냥이는 **옮겨 쓰는 카드**로 받아 주든 안 받아 주든 쓸 수 있게 만들었다."
- 확인을 못 했으면 그대로 말한다: "본선 당일이 주말이라 120 상담만 했고, 주민센터 현장 확인은 다음 검증 계획이다." (지어내지 않는다)

### 1-4. main 합치기 (PM만)
팀원은 자기 브랜치에만 올리고 디스코드에 "수홍님 main에 합쳐 주세요"를 올린다. PM은 자기 AI에게:
| 언제 | PM이 AI에게 하는 말 |
|---|---|
| 01 담당이 올렸다고 하면 (11시쯤, **바로**) | "feat/01-base main에 합쳐줘" → 디스코드에 "다들 최신 main 받아줘 하세요" |
| 누가 급하게 부탁하면 | "feat/0X-... main에 합쳐줘" |
| 12시 30분 | "브랜치 다 합쳐줘" → 결과 표를 디스코드에 올리고, 못 합친 사람에게 "main 받아서 충돌 고쳐줘" 부탁 |
| 13시 30분 | "브랜치 다 합쳐줘" (기능 동결) → 배포 주소로 5장 점검 |
| 아무 때나 | "브랜치 상태 보여줘" (누가 얼마나 올렸는지) |
- AI가 합쳐 보고 build가 깨지면 **스스로 되돌리고** 이유를 알려 준다. main은 항상 build가 되는 상태로 유지된다.
- main으로 push할 때 Claude Code가 허락을 물으면 PM이 허락한다 (팀원이 실수로 올리지 못하게 일부러 묻게 해 둠).

## 2. 시연 시나리오 (피드백 기획 2: 가족과 함께 쓰는 장면이 주 시나리오)

### 등장인물과 준비
- **이순례 (76세, 노원구 상계동, 혼자 삶)**: 기초연금으로 생활. 작년에 보완 요청서를 받고 포기했다.
- **아들 김민수**: 주말에 어머니 집에 와서 폰으로 같이 신청서를 쓴다.
- **딸 (따로 삶)**: 가족 공유 링크를 받는다. (노트북이 딸 역할)
- 준비: 폰 A(아들)에 배포 주소, 노트북 탭 1에 `/demo/notice`, 탭 2는 비워 둠 (가족 링크 열 곳)

### 3분 전체판
| 순서 | 하는 것 | 보여 줄 포인트 |
|---|---|---|
| 1 | `/intro?demo=1` → `👨‍👩‍👧 가족을 도와주고 있어요` → 시작할게요 → 번호 안내 | 누가 쓰나요, 8자리 번호 |
| 2 | `시연용: 앞부분 채우기` | (시간 절약) 질문이 "신청하시는 분은..."으로 바뀐 것 짚기 |
| 3 | 집 질문에서 **어머니 역할이 마이크에**: "보증금 오백에 월세 이십오만 원 내고 살아" | 큰 "듣고 있어요", 한 번에 세 칸, "한 달 월세 / 25만 원" 크게 확인 |
| 4 | 일 소득 `아니오` → 연금 `예` → 마이크 "한 삼십만 원쯤 될 거야" | "약 30만 원, 확인 필요" (틀린 금액이 확정되지 않음) |
| 5 | 저축 `잘 모르겠어요` → 확인 방법 → `나중에 확인할게요` | 어디서 확인하는지 알려 줌 |
| 6 | 나머지 버튼 → 확인 화면 | "확인이 필요한 답 2개" |
| 7 | 내기 전 점검 첫 질문 "확정일자 도장?" `아니요` → 고치는 방법 → `나중에 할게요` | 탈락과 재방문을 줄이는 점검 |
| 8 | 준비 카드: 탭 1 서류 10개, 두세 개 체크 → 탭 2 받으러 갈 곳 → 탭 3 할 말 `🔊` | 세 칸, 안 챙긴 것 먼저 |
| 9 | `가족에게 보내기` → 안내 문구 → 링크를 노트북 탭 2에 열기 | 금액, 답이 안 보이는 가족 화면 |
| 10 | `주민센터에 다녀왔어요` → `서류를 더 내래요` → 노트북 탭 1의 예시 종이 촬영 | |
| 11 | 추가로 챙길 서류: 원문 옆 쉬운 풀이 → 날짜 비교 `맞아요` → **"11월 28일 (토)까지 / 7일 남았어요"** | 원문 대조, 날짜 확인, "각하" 풀이 |
| 12 | 노트북 탭 2 새로고침 | 딸 화면에 "가족분 서명이 필요한 서류", D-7 |
| 13 | `추가 서류를 냈어요` → 제출 완료 | 서류 준비 완료와 제출 완료가 다르게 보임 |

## 3. 발표에서 피드백에 답하기

| 받은 피드백 | 발표에서 할 말 (요지) |
|---|---|
| 주민센터가 받아 주나 | 120 확인 결과 + 받아 주든 안 받아 주든 쓰는 **옮겨 쓰는 카드** |
| 어르신 혼자 쓰기 어렵다 | 주 경로를 **가족, 배움터와 함께**로 바꿨다. 시작할 때 누가 쓰는지 고르면 질문과 안내가 바뀐다 |
| 모르는 금액 | 모르면 **어디서 확인하는지** 알려 주고, 모름과 어림은 **확인 필요**로 표시해 신청서에 확정 값으로 들어가지 않는다 |
| 탈락 줄이기 | **내기 전 점검**: 자주 나오는 보완 사유를 미리 확인. 데이터만 바꾸면 주민센터 실제 사례로 바뀐다 |
| 사진 오인식 | **원문을 옆에** 보여 주고 **날짜는 사용자가 확인**해야 확정. 표, 도장, 손글씨 샘플 9장 시험 결과 (05의 기록) |
| 공유 링크 민감정보 | 누를 때만 생성, **7일 만료, 멈추기**, 가족 화면에는 **금액과 답이 없다** |
| 6자리 코드, RLS | **8자리 + 10분 5회 잠금**, **RLS 켜고 서버에서만 DB 접근**, 신청 건마다 긴 토큰. 이어서 하기와 가족 공유는 다른 코드 |
| pdf-lib 한글 | 공식 양식 좌표 대신 **HTML 인쇄 한 장**으로 바꿔 위험을 없앴다 |
| 모델 미정 | **Claude API**로 정했다. 말 읽기는 빠른 **Haiku 5.5**, 사진 읽기는 정확한 **Sonnet 5.5**, 샘플 시험 결과로 확인 (03, 05의 기록) |

### 특강에서 들은 "발표에서 답해야 할 질문"
- **실제로 이 문제를 겪는 사람이 있나요?** 비수급 빈곤층 규모, 지원을 못 받은 이유로 "과정이 복잡함"과 "서류 제출의 어려움"이 꼽힌 조사 (기획안 근거)
- **도움 없이 쓸 수 있나요?** 혼자도 되지만, 현실적인 주 경로는 가족과 배움터. 그 경로에 맞춰 바꿨다
- **데이터는 어디서?** 서울시 복지 누리집(서울형 기초보장 기준), 보건복지부 사회보장급여 공통서식, 기초생활보장 신청 안내. 서류 규칙과 점검 질문은 **시연용 예시**이고 주민센터 확인 후 교체 예정
- **어디까지 되고 무엇이 안 되나요?** 된다: 질문, 음성, 확인 필요 표시, 점검, 준비 카드, 옮겨 쓰는 카드, 추가 서류 읽기, 가족 공유, 이어서 하기. 안 된다(일부러 뺌): 수급 판정, 로그인, 온라인 실제 제출, 소득 자동 조회, 다른 제도 데이터

### 마지막 장: 다음 검증 계획
- 실제 어르신 3명과 가족이 함께 써 보는 사용 시험 (옆에서 지켜보기)
- 주민센터 담당자에게 옮겨 쓰는 카드와 점검 질문 검토 받기
- 다른 제도 추가 (공통서식 칸 재사용 → 서울시와 자치구 제도 → 전국)

## 5. 최종 점검표 (13시 30분 2차 합치기 뒤, 배포 주소에서)

### 흐름
- [ ] 버튼만으로 시작 → 질문 → 확인 → 점검 → 카드 → 다녀왔어요 → 제출 완료
- [ ] 추가 서류: 사진(또는 예시) → 날짜 확인 → 카드에 붙음 → 추가 서류를 냈어요 → 제출 완료
- [ ] 다른 기기에서 8자리 번호로 이어서 하기 → 현황에 남은 일이 먼저
- [ ] 새로고침해도 같은 자리

### 피드백 반영 확인
- [ ] 가족 모드에서 질문이 "신청하시는 분은..."
- [ ] 잘 모르겠어요 → 확인 방법 → 확인 필요 표시가 확인 화면, 카드, 옮겨 쓰는 카드, 현황에 다 보임
- [ ] 금액을 말하면 "한 달 월세 / 25만 원"처럼 크게 확인, 버튼으로 고치기 가능
- [ ] 카드가 세 칸이고 안 챙긴 서류가 먼저
- [ ] "서류 준비 완료"와 "제출 완료"가 다른 칸, 다른 글
- [ ] 추가로 챙길 서류에 원문이 같이 보이고 날짜 확인 단계가 있음
- [ ] 가족 화면에 금액, 답, 번호가 없고, 멈추면 안 열림
- [ ] 옮겨 쓰는 카드가 A4 한 장, 모름 칸은 빈칸 + 확인 필요
- [ ] 모든 화면에 지금 할 일 줄

### 접근성
- [ ] 375px 폭에서 질문 화면이 스크롤 없이 보임
- [ ] 버튼 높이 64px 이상, 아이콘만 있는 버튼 없음
- [ ] 모든 화면에 뒤로, 처음으로, 다시 듣기가 같은 자리
- [ ] 소리 끄기, 글씨 크게

### 안전
- [ ] 화면과 AI 출력 어디에도 "받을 수 있어요", "대상이에요", "탈락"이 없다
- [ ] 결과 화면마다 "받을 수 있는지는 구청에서 조사해서 정해요"
- [ ] DB에 이름, 주민등록번호, 전화번호, 사진이 없다
- [ ] 06의 보안 점검표 통과
- [ ] `.env.local`이 GitHub에 없다
