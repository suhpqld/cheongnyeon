## 이 기능이 하는 일
누가 쓰는지 묻고, 신청 건을 만들고, 신청서 칸을 **쉬운 질문 하나씩** 묻는다. 버튼, 숫자판, 말(03의 MicButton)로 답을 받고, 모르는 값은 **어디서 확인하는지** 알려 주고, 대충 말한 금액은 **확인 필요**로 표시한다. 마지막에 확인 화면에서 한 줄씩 보고 고친다.

## API

### 🔒 `GET /api/apps/[id]/form`
- `requireApp` → program, form_field(sortOrder 순), answer(field_id로 key 연결) 읽기
- 응답 `{ program: Program, fields: FormField[], answers: AnswerMap }` (camelCase, `answers`는 `fieldKey`가 키)
- `app.programId`가 없으면 (추가 서류로 바로 시작한 신청 건) `seoul_basic`을 쓴다.

### 🔒 `PUT /api/apps/[id]/answers`
- 요청 `{ answers: Answer[] }` (한 번에 여러 개 가능: 한 번 말에 여러 칸)
- 각 답을 `validateAnswer`(아래)로 검사 → 통과한 것만 `(application_id, field_id)`로 upsert, `updated_at = now()`
- 통과 못 한 게 있으면 400 `{ error: 'invalid', message: '답을 다시 확인해 주세요.', keys: [...] }` (통과한 것은 저장)
- `application.updated_at` 갱신
- 응답 `{ answers: AnswerMap }` (전체)

## 규칙 `lib/rules/form.ts` (브라우저, 서버 둘 다 씀)
- `questionText(field, helperMode)` → self면 `questionEasy`, 아니면 `questionHelper`
- `nextField(fields, answers)`: `visibleFields`(01) 중 답이 없는 첫 질문. 없으면 null
- `prevField(fields, answers, currentKey)`: 현재보다 앞의 보이는 질문 중 마지막
- `progress(fields, answers, currentKey)` → `{ index, total, remaining }` (total = 보이는 질문 수)
- `validateAnswer(field, value)`:
  | type | 통과 |
  |---|---|
  | yes_no | boolean |
  | choice | options의 value 중 하나 |
  | district | `SEOUL_DISTRICTS` 중 하나 ("노원"이면 "노원구"로 고쳐서) |
  | count | 정수, min~max |
  | money | 0 이상 정수, max 이하 |
  | text | 공백 빼고 1~100자 |
  | `'unknown'` | `allowUnknown`일 때만 |
- `checkNeeded(fields, answers)` → 보이는 질문 중 `'unknown'`이거나 `isApproximate`인 것 목록 (04, 06도 같은 기준으로 센다)

### 말로 대답한 결과 처리 (`MicButton`의 `onResult(result, utterance)`)
1. `result.value`가 null이거나 `confidence === 'low'`이거나 `validateAnswer` 실패 → **되묻기** 상태
2. `result.value === 'unknown'` → 모름 안내 상태
3. 통과 + high:
   - **money, count, district, text** → **크게 확인** 상태
   - **yes_no, choice** → 화면에 "알아들었어요: {heardAs}"를 1.5초 크게 보여 주고 읽어 준 뒤("{heardAs}로 적을게요") 저장(`inputMethod: 'voice'`, `rawSpeech: utterance`) → 다음
4. `result.otherValues`: 각각 `validateAnswer` 통과한 것만 같은 PUT에 같이 저장. 크게 확인 화면 아래에 "같이 알아들었어요: 보증금 500만 원" 목록으로 보여 준다. (그 질문은 다음에 건너뜀)

   - 확인 필요인 줄은 "⚠ 확인 필요" 글자 + 굵은 테두리
5. `맞아요, 다음으로` (primary)
6. Disclaimer

|---|---|
| 줄 누르기 | 그 줄 읽기: "{칸 이름}, {값}" |
| `고치기` | `/a/[id]/q?field={key}&from=review` |
| `🔊 전체 읽어 주기` | 한 줄씩 읽고 읽는 줄 강조. 읽는 중엔 `■ 멈추기` |
| `맞아요, 다음으로` | 보이는 필수 칸 중 답 없는 게 있으면 그 질문으로 + "이것만 더 대답해 주세요." / 다 있으면: status가 drafting이면 `PATCH status preparing` → `/a/[id]/precheck` |
| `← 뒤로` | 마지막 보이는 질문 |
- `'unknown'`은 "답이 있는 것"으로 본다 (모름도 답). 확인 필요는 막지 않고 알려만 준다.
