# 01 기반과 뼈대

> **AI에게:** `docs/00_공통_먼저읽기.md`를 먼저 끝까지 읽었는지 확인한다. 이 기능은 **다른 네 명이 기다리고 있는 기반**이다. 예쁘게보다 **빨리, 약속(00의 11, 12, 13장)과 정확히 같게** 만든다. 목표 시간 40분.

## 이 기능이 하는 일
모두가 같이 쓰는 바탕을 만든다: 패키지, DB 테이블과 시연 데이터, 공통 타입, 서버 인증(토큰), DB와 AI를 부르는 서버 함수, 공통 화면 부품, 그리고 **모든 화면의 빈 자리 파일**. 이게 main에 들어가야 다른 사람들이 각자 화면을 채울 수 있다.

## 추천 담당
임채희 (백엔드). 끝나면 06으로 넘어간다.

## 시작 전 확인
1. `git checkout main && git pull origin main && git checkout -b feat/01-base`
2. 저장소 상태 확인: `package.json`(Next.js, Tailwind 버전), `app` 폴더 위치(`src/app`이면 이 문서의 `app/`을 `src/app/`으로, `lib/`도 같은 기준으로 맞춘다), 이미 있는 파일.
   - 설치된 Next.js 버전 문법을 따른다. (페이지와 라우트의 `params`가 Promise인 버전이면 `await params`)
   - Tailwind v4면 `app/globals.css`의 `@theme`에 색 토큰을 둔다.
3. 루트에 예전 `PRD.md`가 있으면 지운다. (docs/로 바뀜)

### `supabase/schema.sql`
```sql
create extension if not exists pgcrypto;

create table if not exists welfare_program (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,
  name text not null,
  form_type text not null default '공통서식',
  summary_easy text,
  apply_place text,
  contact text,
  after_submit_easy text,
  created_at timestamptz not null default now()
);

create table if not exists form_field (
  id uuid primary key default gen_random_uuid(),
  program_id uuid not null references welfare_program(id) on delete cascade,
  key text not null,
  common_key text,
  label text not null,
  section text not null,
  question_easy text not null,
  question_helper text not null,
  help_easy text,
  type text not null check (type in ('yes_no','choice','district','count','money','text')),
  options jsonb,
  required boolean not null default true,
  allow_unknown boolean not null default false,
  min_value bigint,
  max_value bigint,
  show_if jsonb,
  confirm_label text,
  check_guide text,
  sort_order int not null,
  unique (program_id, key)
);

create table if not exists document_rule (
  id uuid primary key default gen_random_uuid(),
  program_id uuid not null references welfare_program(id) on delete cascade,
  doc_name text not null,
  easy_explain text,
  issue_place text,
  place_group text not null check (place_group in ('home','onsite','bank','work','tax','gov24')),
  condition jsonb,
  sort_order int not null default 0,
  unique (program_id, doc_name)
);

create table if not exists precheck_rule (
  id uuid primary key default gen_random_uuid(),
  program_id uuid not null references welfare_program(id) on delete cascade,
  check_question text not null,
  why_easy text not null,
  fix_easy text not null,
  related_doc text,
  condition jsonb,
  sort_order int not null default 0,
  unique (program_id, check_question)
);

create table if not exists application (
  id uuid primary key default gen_random_uuid(),
  program_id uuid references welfare_program(id),
  status text not null default 'drafting' check (status in ('drafting','preparing','submitted','supplementing')),
  helper_mode text not null default 'self' check (helper_mode in ('self','family','helper')),
  resume_code text unique not null,
  app_token text unique not null,
  share_code text unique,
  share_expires_at timestamptz,
  submitted_at timestamptz,
  ai_call_count int not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  expires_at timestamptz not null default (now() + interval '30 days')
);

create table if not exists answer (
  id uuid primary key default gen_random_uuid(),
  application_id uuid not null references application(id) on delete cascade,
  field_id uuid not null references form_field(id) on delete cascade,
  value jsonb,
  raw_speech text,
  input_method text check (input_method in ('voice','button','text','unknown')),
  is_approximate boolean not null default false,
  updated_at timestamptz not null default now(),
  unique (application_id, field_id)
);

create table if not exists supplement_request (
  id uuid primary key default gen_random_uuid(),
  application_id uuid not null references application(id) on delete cascade,
  source_text text,
  parsed_json jsonb not null,
  deadline date,
  deadline_confirmed boolean not null default false,
  office_contact text,
  submitted_at timestamptz,
  created_at timestamptz not null default now()
);

create table if not exists checklist_item (
  id uuid primary key default gen_random_uuid(),
  application_id uuid not null references application(id) on delete cascade,
  supplement_id uuid references supplement_request(id) on delete set null,
  doc_name text not null,
  easy_explain text,
  issue_place text,
  place_group text not null default 'onsite' check (place_group in ('home','onsite','bank','work','tax','gov24')),
  source text not null default 'base' check (source in ('base','supplement')),
  due_date date,
  is_done boolean not null default false,
  also_requested boolean not null default false,
  created_at timestamptz not null default now()
);

create table if not exists precheck_result (
  id uuid primary key default gen_random_uuid(),
  application_id uuid not null references application(id) on delete cascade,
  rule_id uuid not null references precheck_rule(id) on delete cascade,
  result text not null check (result in ('yes','no','unknown')),
  updated_at timestamptz not null default now(),
  unique (application_id, rule_id)
);

create table if not exists resume_attempt (
  id uuid primary key default gen_random_uuid(),
  ip text not null,
  success boolean not null,
  created_at timestamptz not null default now()
);
create index if not exists resume_attempt_ip_time on resume_attempt (ip, created_at);
```

### `lib/format.ts`
- `formatWon(n)`: 0 → "없어요", 250000 → "25만 원", 5000000 → "500만 원", 1234567 → "약 123만 원"(만 원 미만이 남으면 "약" + 만 원 단위 반올림), 150000000 → "1억 5,000만 원", 1000000000 → "10억 원"
- `displayAnswer(field, a)`:
  | 경우 | 표시 |
  |---|---|
  | 답 없음 | "아직 안 했어요" |
  | `'unknown'` | "잘 모름 (확인 필요)" |
  | money + `isApproximate` | "약 30만 원 (확인 필요)" |
  | money | `formatWon` |
  | yes_no | true "있어요" / false "없어요" |
  | choice | 선택지 label |
  | count | 1 → "1명 (혼자)", 나머지 "3명" |
  | district, text | 그대로 |
- `formatCode("48291357")` → "4829 1357"
- `todayKST()`: **Asia/Seoul 기준** 오늘 "YYYY-MM-DD" (Vercel 서버는 UTC라서 `Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Seoul' })`)
- `formatDateKo("2026-11-28")` → "11월 28일 (토)"
- `ddayFrom(deadline, today = todayKST())` → 일 수 (deadline − today)
- `ddayLabel(n)`: n>0 → { big: "D-7", text: "7일 남았어요" }, 0 → { big: "D-DAY", text: "오늘까지예요" }, n<0 → { big: "기한 지남", text: "기한이 3일 지났어요" }

### `lib/rules/condition.ts`
- `matches(cond, answers)`: `null` → true / 배열 → 모두 맞아야 true / 기준 칸의 답이 없거나 `'unknown'`이면 false / `eq`, `neq`, `in`(배열 포함), `gt`, `lt`
- `isVisible(field, answers)` = `matches(field.showIf, answers)`
- `visibleFields(fields, answers)` = sortOrder 순으로 보이는 것만
- 안 보이게 된 질문의 답은 지우지 않고 계산에서 뺀다 (모든 기능 공통 규칙)

### `lib/client/*`
- `session.ts`: localStorage `boknyang.session`에 `Session` 저장, 읽기, 지우기. 서버 렌더링 중에는 null.
- `api.ts`: `apiFetch(path, { method, body })`. 세션이 있으면 `x-app-token` 헤더. 응답이 ok가 아니면 `ApiError { status, error, message }`를 던진다. 401이면 세션을 지우지 말고 그대로 던진다 (화면이 이어서 하기로 안내).
- `settings.ts`: `useSettings()`. `fontSize`가 large면 `<html>`에 `text-large` 클래스 (기본 글자 24px).
- `tts.ts`:
  - `speak(text)`: 소리 꺼짐이면 아무것도 안 함. 읽던 것 멈추고, 문장 끝(. ? ! 요 다 니다 뒤 공백)으로 나눠 차례로 `SpeechSynthesisUtterance`. `lang='ko-KR'`, `rate=0.9`, 한국어 목소리 우선 (`speechSynthesis.getVoices()`는 `voiceschanged` 뒤에 채워지므로 기다렸다가 고름).
  - `stopSpeaking()`
  - `useAutoSpeak(text)`: 화면이 열릴 때 한 번. 사용자가 페이지에서 한 번이라도 누르기 전이면 조용히 넘어감 (브라우저가 막음). 화면을 떠나면 멈춤.

### `lib/server/*`
- `db.ts`: `getDb()`가 처음 불릴 때 `createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SECRET_KEY!, { auth: { persistSession: false } })`를 만들어 재사용한다. **파일 맨 위에서 바로 만들지 않는다** (`npm run build`가 라우트 파일을 불러올 때 환경 변수가 없으면 깨지기 때문). 환경 변수가 없으면 그때 `throw fail(500, 'config', '서버 설정이 아직 안 됐어요.')`. `toCamel`, `toSnake`. 이 파일 맨 위에 `import 'server-only'`가 가능하면 넣는다 (안 되면 생략).
- `auth.ts`:
  - `newToken()`: `crypto.randomBytes(24).toString('base64url')` (32자)
  - `newResumeCode()`: 8자리 숫자 문자열 (첫 자리 0 가능)
  - `newShareCode()`: 10자, 헷갈리는 글자(0, o, 1, l, i) 뺀 소문자와 숫자
  - `requireApp(req, appId)`: 헤더 `x-app-token`과 DB `app_token` 비교. 없거나 다르면 `throw fail(401, 'token', '다시 이어서 하기 번호를 넣어 주세요.')`, 신청 건이 없으면 404. 맞으면 DB 행을 돌려준다.
- `http.ts`: `ok`, `fail`, `withErrors`
- `ai.ts`: `callAI(...)` (**Claude API**, 패키지 설치 없이 `fetch`)
  - `POST https://api.anthropic.com/v1/messages`
  - 헤더: `x-api-key: ${ANTHROPIC_API_KEY}`, `anthropic-version: 2023-06-01`, `content-type: application/json`
  - 모델: kind가 text면 `CLAUDE_TEXT_MODEL`(없으면 `claude-haiku-5-5`), vision이면 `CLAUDE_VISION_MODEL`(없으면 `claude-sonnet-5-5`)
  - 본문: `{ model, max_tokens: kind === 'vision' ? 2048 : 1024, temperature: 0, system, messages: [{ role: 'user', content }] }`
  - content: text면 `[{ type: 'text', text: user }]`. vision이면 사진을 먼저: `[{ type: 'image', source: { type: 'base64', media_type: 'image/jpeg', data: base64 } }, { type: 'text', text: user }]` (`data`는 `imageDataUrl`에서 `data:image/jpeg;base64,` 앞부분을 뗀 것)
  - 응답: `content` 배열에서 `type === 'text'`인 것들의 `text`를 이어 붙인다
  - JSON 꺼내기: ```json 울타리 제거 → 첫 `{`부터 마지막 `}`까지 잘라 `JSON.parse`. 실패하면 messages에 방금 응답(assistant)과 "JSON 하나만 다시 보내 주세요"(user)를 붙여 한 번 더 요청. 또 실패하면 `throw new AiError('json')`
  - HTTP 429, 529(과부하), 500대는 1초 쉬고 1번 재시도. 401은 `AiError('key')`, 잔액 부족(400 + credit)은 `AiError('billing')`
  - `AbortController`로 `timeoutMs`(기본 25000) 지나면 `AiError('timeout')`
- `ai-limit.ts`: `useAiCall(appId)`: `ai_call_count`가 `AI_CALL_LIMIT` 이상이면 `throw fail(429, 'limit', '오늘은 말로 대답하기를 많이 썼어요. 버튼으로 대답해 주세요.')`, 아니면 1 올린다.

## P0-4. 신청 건 API (5분)
- `POST /api/apps` `{ programCode, helperMode, startStatus? }`
  - program 찾기 (없으면 400), `resume_code`는 겹치면 다시 뽑기 (unique 오류 시 최대 5번)
  - `status = startStatus ?? 'drafting'`
  - 응답 `{ appId, token, resumeCode }`
- 🔒 `GET /api/apps/[id]` → `{ app, program }`. `app`에는 `appToken`, `shareCode`를 **넣지 않는다**. `shareActive = share_code가 있고 share_expires_at이 지금 이후`.
- 🔒 `PATCH /api/apps/[id]/status` `{ status }` → `ALLOWED_STATUS_CHANGES`에 없으면 409 `{ error: 'status', message: '지금은 그 단계로 갈 수 없어요.' }`. 같은 상태면 그대로 200. submitted로 가면 `submitted_at = now()`. `updated_at`도 갱신.
