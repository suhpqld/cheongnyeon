# 05 사진 모델 시험 기록

## 시험 준비

- 시연용 예시 종이: `/demo/notice?v=1`, `?v=2`, `?v=3`
- 각 종이를 시연 폰으로 반듯하게, 비스듬히, 어둡게 촬영해 총 9장을 만든다.
- 같은 사진과 `lib/ai/supplement-prompt.ts` 프롬프트로 Claude Sonnet 5.5와 Claude Haiku 5.5를 비교한다.
- 기한, 서류 3개, 각 서류의 원문이 모두 정확한지 원본과 직접 대조한다.
- 실제 인물·기관 정보는 사용하지 않는다. API 키는 `.env.local`에서만 읽고 기록하거나 커밋하지 않는다.

## 결과

2026-11-21에 시연용 사진 3장(v1, v2, v3)을 받아 Sonnet 5.5와 Haiku 5.5에 각각 요청했다. **6건 모두 HTTP 401 `authentication_error`**로 끝나 사진 분석 결과는 없었다. API 키가 유효한지 PM이 Claude Console에서 확인한 뒤 다시 시험한다. 키 값은 이 기록에 남기지 않는다.

같은 날 새로 받은 `.env.local`로 `x-api-key`와 `Authorization: Bearer` 방식도 각각 확인했으나 모두 HTTP 401이었다. 사진 정확도는 아직 측정하지 못했다.

## 키 없이 확인한 예시 흐름

- 시연용 신청 건을 만들어 `예시 종이로 해보기` 결과 3개를 확인했다.
- 기존 임대차계약서 1개는 합쳐지고, 나머지 서류 2개는 새로 추가됐다.
- 기한 확인 전 상태, 날짜 수정 후 관련 준비 카드의 기한 변경, 제출 완료 상태를 API로 확인했다.
- 시험용 신청 건과 관련 데이터는 삭제했다.

## 발표에 쓸 한 줄

시험을 마친 뒤 실제 성공 장수만 넣는다: “표, 도장, 손글씨 샘플 9장 중 __장에서 서류와 기한을 정확히 읽었고, 틀릴 때를 대비해 원문을 같이 보여 주고 날짜는 사용자가 확인합니다.”
